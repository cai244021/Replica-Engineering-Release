# 需求文档：打开方式（Open With）

## 1. 功能概述

"打开方式"提供两种入口，允许用户将表格中选中的对象在不同的 3DExperience App 中打开：

| 入口 | 位置 | 说明 |
|------|------|------|
| **工具栏下拉** | 表格上方工具栏"打开方式"按钮 | 使用当前表格选中行 `currentTableRow` |
| **行内右键菜单** | 表格行操作菜单 → "打开方式" 子菜单 | 使用该行数据 `rowOverride` |

下拉菜单包含 **5 个选项**：

| 序号 | 名称 | 图标 | appId | 打开方式 |
|------|------|------|-------|----------|
| 1 | **3D Markup** | EditPen | `ENOR3D_AP` | 修改 Dashboard hash 跳转 |
| 2 | **3D Navigate** | Compass | `ENXDISC_AP` | 修改 Dashboard hash 跳转 |
| 3 | **3DPlay** | VideoPlay | `X3DPLAW_AP` | 修改 Dashboard hash 跳转 |
| 4 | **更多应用程序** | Plus | — | 打开原生罗盘面板 |

---

## 2. 用户操作流程

### 2.1 预定义 App（3D Markup / 3D Navigate / 3DOperations Viewer / 3DPlay）

```
用户选中表格行 → 点击"打开方式" → 选择预定义 App
                                        ↓
                              提取行数据中的 objectId / objectType 等
                                        ↓
                              构建 3DXContent JSON payload
                                        ↓
                              拼装 Dashboard URL hash
                                        ↓
                          修改父窗口 location.hash → App 全屏加载对象
```

### 2.2 更多应用程序

```
用户选中表格行 → 点击"打开方式" → 选择"更多应用程序"
                                        ↓
                              构建 3DXContent payload
                                        ↓
                          调用 X3DContent.setX3DContent(payload)
                                        ↓
                          调用 CompassManager.open() 打开罗盘
                                        ↓
                          用户在罗盘中选择任意 App → 加载对象
```

### 2.3 罗盘已打开时自动同步

```
罗盘已打开 → 用户切换表格选中行
                    ↓
          watch(currentTableRow) 触发
                    ↓
          检查 CompassManager.isOpen()
                    ↓
          是 → X3DContent.setX3DContent(新 payload)
          否 → 不执行
```

## 3. 技术实现

### 3.1 核心代码结构

文件位置：`src/views/library/LibraryView.vue`

```
handleOpenWithCommand(command, rowOverride?)     ← 统一入口
├── command === 'more'
│   └── openNativeCompass(row)                   ← 打开原生罗盘
│       ├── buildX3DContentPayload(row)          ← 构建 payload
│       ├── X3DContent.setX3DContent(payload)    ← 设置内容
│       └── CompassManager.open()                ← 打开罗盘
│
└── command === '3D Markup' | '3D Navigate' | '3DOperations Viewer' | '3DPlay'
    ├── buildX3DContentPayload(row)              ← 构建 payload（复用）
    ├── JSON.stringify → encodeURIComponent      ← 编码
    └── 修改 window.top.location.hash            ← Dashboard hash 跳转
```

### 3.2 appId 映射表

```typescript
const OPEN_WITH_APP_ID: Record<string, string> = {
    '3D Markup': 'ENOR3D_AP',
    '3D Navigate': 'ENXDISC_AP',
    '3DPlay': 'X3DPLAW_AP'
};
```

### 3.3 3DXContent 协议 Payload

由 `buildX3DContentPayload(row)` 构建：

```typescript
{
    protocol: '3DXContent',
    version: '2.0',
    source: 'X3DSEAR_AP',
    widgetId: '',
    data: {
        items: [{
            objectId,            // physicalid > mxid > ds6w:identifier > resourceid > id
            objectType,          // ds6w:type > type
            envId: 'OnPremise',
            serviceId: '3DSpace',
            displayName,         // ds6w:label > label > title > objectId
            displayType,         // 同 objectType
            contextId,           // baseInfoStore.securityContext
            objectTaxonomies     // 固定分类列表
        }]
    }
}
```

### 3.4 字段取值优先级

通过 `pickRowField(row, ...keys)` 函数实现，按顺序尝试取值，返回第一个非空值：

| 目标字段 | 取值顺序 |
|----------|----------|
| `objectId` | `physicalid` → `mxid` → `ds6w:identifier` → `resourceid` → `id` |
| `objectType` | `ds6w:type` → `type` |
| `displayName` | `ds6w:label` → `label` → `title` → 兜底 `objectId` |

### 3.5 objectTaxonomies 固定分类列表

与后端 `getDashBoardPSELink` 一致：

```typescript
const X3D_OBJECT_TAXONOMIES = [
    'PLMEntity', 'PLMReference', 'PLMCoreReference',
    'LPAbstractReference', 'PHYSICALAbstractReference',
    'VPMReference', '3DPart', 'XCADExtension', 'CN_PartInfo'
];
```

### 3.6 预定义 App 的 Hash 跳转实现

**Dashboard URL 结构**：

```
<dashboardUrl>/#/tabId:New%20Tab/app:<appId>/content:X3DContentId=<encodedPayload>
```

**dashboardUrl 获取逻辑**：

1. 优先从 `baseInfoStore.dashboardUrl` 或 `localStorage('dashboardUrl')` 获取
2. 去除 `/api/...` 后缀（i3DXCompassServices 返回的可能是代理地址）
3. 兜底使用 `window.location.origin + '/3ddashboard'`
4. 验证必须以 `http://` 或 `https://` 开头

**跳转方式**：

```typescript
// 主要方式：修改父窗口 hash（同源，不刷新 Dashboard）
const hashSuffix = `/app:${appId}/content:X3DContentId=${encoded}`;
const top = window.top || window.parent || window;
const currentHash = top.location.hash || '';
const baseHash = currentHash.replace(/\/app:[^/]+(?:\/content:[^]*)?$/, '');
top.location.hash = (baseHash || '#/tabId:New%20Tab') + hashSuffix;

// 备用方式：跨域失败时整页跳转
(window.top || window).location.href = fullUrl;
```

### 3.7 罗盘打开实现

通过父窗口 RequireJS 模块注册表访问 3DDashboard 内部模块：

```typescript
const topWin = window.top || window.parent || window;
const ctx = topWin.requirejs?.s?.contexts?._ || topWin.require?.s?.contexts?._;
```

| 步骤 | 模块 | 方法 |
|------|------|------|
| 设置内容 | `DS/i3DXCompass/X3DContent` | `setX3DContent(payload)` |
| 打开罗盘 | `DS/Dashboard/CompassManager` | `open()` |
| 检查状态 | `DS/Dashboard/CompassManager` | `isOpen()` |

**备用打开方式**（CompassManager 不可用时）：

```typescript
topWin.document.querySelector('.compass-small')?.click();
```

### 3.8 选中行同步

```typescript
watch(currentTableRow, (newRow) => updateCompassContent(newRow));
```

`updateCompassContent` 逻辑：
1. 开发模式 → 跳过
2. `CompassManager.isOpen()` 为 false → 跳过
3. 构建新 payload → `X3DContent.setX3DContent(payload)`

### 4.2 行内右键菜单（LibraryTable.vue）

通过 `el-popover` 弹出子菜单，调用 `handleOpenWith(row, appName)` → `emit('open-with', row, app)`。

父组件 `LibraryView.vue` 监听 `@open-with` 事件，转发到 `handleOpenWithCommand(app, row)`。

### 4.3 显示条件

工具栏"打开方式"下拉通过 `toolbarConfig.openWith` 控制是否显示，仅在表格展示"内容"数据时启用。

## 6. 前置条件与约束

| 条件 | 说明 |
|------|------|
| **运行环境** | 必须在 3DDashboard 内以 Widget 方式运行。开发模式下罗盘不可用，hash 跳转也无法生效。 |
| **选中行** | 必须有选中行且包含有效 `objectId`。未选中时提示"请先选择一行数据"。 |
| **跨窗口访问** | 需要能访问 `window.top` 的 RequireJS 上下文（同源策略）。 |
| **安全上下文** | `contextId` 来自 `baseInfoStore.securityContext`，需应用初始化时已获取。 |
| **Dashboard URL** | 预定义 App 跳转需要有效的 Dashboard 地址，否则提示错误。 |

---

## 7. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 未选中行 | `ElMessage.warning('请先选择一行数据')` |
| 未知 App 名称 | `ElMessage.warning('未知的打开方式：xxx')` |
| 无法获取 objectId | `ElMessage.error('无法获取对象 physicalid')` |
| Dashboard URL 为空 | `ElMessage.error('未获取到 3DDashboard 地址，无法打开')` |
| 开发模式打开罗盘 | `ElMessage.info('开发模式下无法打开原生罗盘')` |
| RequireJS/CompassManager 不可用 | 静默降级到 DOM 点击 `.compass-small` |
| 修改父 hash 失败（跨域） | 降级到 `window.location.href` 整页跳转 |
