# 需求文档：打开方式 —— 更多应用程序

## 1. 功能概述

"更多应用程序"是"打开方式"（Open With）下拉菜单中的一个选项。用户在库表格中选中一行内容数据（文档 / 图纸 / 零件 / 产品等），点击"更多应用程序"后，系统会：

1. 打开 **3DDashboard 原生罗盘（Compass）面板**，展示平台上所有可用的应用程序列表。
2. 将当前选中对象的信息（`3DXContent` 协议）设置到罗盘的内容上下文中。
3. 用户在罗盘中点击任意 App 时，该 App 会自动加载选中的对象数据。
4. 若罗盘已打开，用户在表格中切换选中行时，罗盘的内容上下文会**自动同步更新**，确保再次点击 App 时加载的是最新选中的对象。

文件位置：`src/views/library/LibraryView.vue`

**与"打开方式"预定义 App 的区别**：预定义 App（3D Markup / 3D Navigate / 3DOperations Viewer / 3DPlay）通过修改 `location.hash` 直接跳转到目标 App 并携带内容；"更多应用程序"则打开原生罗盘面板，由用户自行选择 App。

---

## 2. 用户操作流程

### 2.1 基本流程

```
用户选中表格行 → 点击工具栏"打开方式" → 选择"更多应用程序"
                                              ↓
                                    设置 X3DContent 到罗盘
                                              ↓
                                    打开原生罗盘面板
                                              ↓
                              用户在罗盘中点击目标 App
                                              ↓
                                App 加载选中对象的数据
```

### 2.2 切换选中行场景

```
罗盘已打开 → 用户在表格中选中另一行
                      ↓
            自动更新罗盘 X3DContent
                      ↓
            用户点击罗盘中的 App
                      ↓
            App 加载最新选中对象的数据
```

## 3. 技术实现

### 3.1 入口与调用链

| 层级 | 函数 / 组件 | 说明 |
|------|-------------|------|
| UI 层 | 工具栏"打开方式"下拉菜单 / 行内右键菜单 | 触发 `command = 'more'` |
| 调度层 | `handleOpenWithCommand(command, rowOverride?)` | 统一入口，`command === 'more'` 时调用 `openNativeCompass(row)` |
| 核心层 | `openNativeCompass(row?)` | 构建 payload → 设置 X3DContent → 打开罗盘 |
| 辅助层 | `buildX3DContentPayload(row)` | 根据行数据构建标准 `3DXContent` 协议 payload |
| 同步层 | `updateCompassContent(row)` | 罗盘已打开时，切换选中行自动更新内容 |
| 监听层 | `watch(currentTableRow, ...)` | 监听表格选中行变化，触发 `updateCompassContent` |

### 3.2 3DXContent 协议 Payload

构建函数：`buildX3DContentPayload(row)`

```typescript
{
  protocol: '3DXContent',
  version: '2.0',
  source: 'X3DSEAR_AP',
  widgetId: '',
  data: {
    items: [
      {
        objectId,          // 来自 physicalid / mxid / ds6w:identifier / resourceid / id
        objectType,        // 来自 ds6w:type / type
        envId: 'OnPremise',
        serviceId: '3DSpace',
        displayName,       // 来自 ds6w:label / label / title，兜底为 objectId
        displayType,       // 同 objectType
        contextId,         // 来自 baseInfoStore.securityContext
        objectTaxonomies   // 固定分类列表（见 3.3）
      }
    ]
  }
}
```

**字段取值优先级**（通过 `pickRowField` 函数实现）：

| 字段 | 优先级从高到低 |
|------|---------------|
| `objectId` | `physicalid` → `mxid` → `ds6w:identifier` → `resourceid` → `id` |
| `objectType` | `ds6w:type` → `type` |
| `displayName` | `ds6w:label` → `label` → `title` → `objectId`（兜底） |

### 3.3 objectTaxonomies 分类列表

与后端 `getDashBoardPSELink` 实现一致的固定分类列表：

```typescript
const X3D_OBJECT_TAXONOMIES = [
  'PLMEntity',
  'PLMReference',
  'PLMCoreReference',
  'LPAbstractReference',
  'PHYSICALAbstractReference',
  'VPMReference',
  '3DPart',
  'XCADExtension',
  'CN_PartInfo'
];
```

### 3.4 打开罗盘的实现

通过父窗口 3DDashboard Shell 的 RequireJS 模块注册表访问平台内部模块：

#### 3.4.1 设置内容（关键步骤）

```
父窗口 RequireJS → ctx.defined['DS/i3DXCompass/X3DContent'] → setX3DContent(payload)
```

调用 `X3DContent.setX3DContent(contentPayload)` 将选中对象信息注册到罗盘的内容上下文。当用户在罗盘中点击任意 App 时，该 App 会自动接收此内容并加载对应的对象。

#### 3.4.2 打开罗盘面板

**主要方式**：
```
父窗口 RequireJS → ctx.defined['DS/Dashboard/CompassManager'] → open()
```

**备用方式**（CompassManager 不可用时）：
```
父窗口 DOM → document.querySelector('.compass-small') → click()
```

#### 3.4.3 RequireJS 模块访问方式

```typescript
const topWin = window.top || window.parent || window;
const ctx = topWin.requirejs?.s?.contexts?._ || topWin.require?.s?.contexts?._;
const mod = ctx?.defined?.['模块名'];
```

### 3.5 选中行变化时自动同步

```typescript
watch(currentTableRow, (newRow) => updateCompassContent(newRow));
```

`updateCompassContent` 的逻辑：

1. 检查是否为开发模式（开发模式跳过）
2. 检查罗盘是否已打开：`CompassManager.isOpen()`
3. 若罗盘已打开，构建新的 payload 并调用 `X3DContent.setX3DContent(payload)` 更新内容
4. 若罗盘未打开，不执行任何操作

## 4. 涉及的平台模块

| 模块路径 | 用途 | 关键方法 |
|----------|------|----------|
| `DS/i3DXCompass/X3DContent` | 管理罗盘的内容上下文 | `setX3DContent(payload)` / `getX3DContent()` |
| `DS/Dashboard/CompassManager` | 控制罗盘面板的打开/关闭 | `open()` / `close()` / `isOpen()` / `subscribeOnOpen()` / `subscribeOnClose()` |

---

## 5. 前置条件与约束

| 条件 | 说明 |
|------|------|
| 运行环境 | 必须在 3DDashboard 内作为 Widget 运行（iframe 嵌入）。开发模式下会提示"开发模式下无法打开原生罗盘"。 |
| 选中行数据 | 必须有表格选中行，且行数据中包含有效的 `objectId`（`physicalid` / `mxid` 等）。 |
| 跨窗口访问 | 需要能访问 `window.top` 或 `window.parent` 的 RequireJS 上下文（同源策略）。 |
| 安全上下文 | `contextId` 来自 `baseInfoStore.securityContext`，需要在应用初始化时已正确获取。 |

---

## 6. 与其他模块的关系

- **`handleOpenWithCommand`**：统一的"打开方式"调度入口，`command === 'more'` 分支调用本功能。
- **`currentTableRow`**：Pinia 或 ref 管理的当前表格选中行，变化时触发罗盘内容同步。
- **`baseInfoStore`**：提供 `securityContext`（安全上下文）。
- **`pickRowField`**：通用的行字段取值工具函数，兼容 `ds6w:*` 和简化字段名。
- **预定义 App 打开方式**：共享 `buildX3DContentPayload` 构建 payload（`OPEN_WITH_APP_ID` 映射表中的 4 个预设 App 使用 hash 跳转方式）。

---

## 7. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 未选中行 | `ElMessage.warning('请先选择一行数据')` |
| 开发模式 | `ElMessage.info('开发模式下无法打开原生罗盘')` |
| RequireJS 上下文不可用 | 静默降级到 DOM 点击备用方式 |
| DOM 罗盘元素不存在 | 静默忽略 |
| 跨域访问失败 | `try-catch` 捕获，静默忽略 |
